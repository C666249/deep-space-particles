# 深空 · Deep Space

一个可交互的 3D 深空粒子背景，用手势驱动。

- **3 / 2 / 1** — 比出手指数，两万颗星尘汇聚成对应的数字
- **握拳** — 星尘收拢，凝成一颗会呼吸的心
- **张开手掌** — 满屏烟花绽放，爱心炸裂成光

## 在线体验

https://c666249.github.io/deep-space-particles/

> 摄像头需要 https 环境，GitHub Pages 天然满足。画面只在本机通过 MediaPipe 识别，不上传任何数据。

## 技术

- 纯手写 WebGL（无 three.js 依赖），单一 shader 点精灵 + 加色混合
- 20,000 粒子弹簧回归系统，数字字形通过 canvas 采样、爱心通过参数方程采样
- MediaPipe Hands 做手部关键点追踪，只数食指~小指，更稳定
- **多 CDN 自动切换**：npmmirror（国内镜像，优先）→ jsdelivr → fastly → unpkg，页面加载即并行探测，哪个通用哪个
- 右上角常驻状态灯：摄像头 / 手势引擎 / 实时识别到几根手指，出问题一眼能看出卡在哪
- 没有摄像头也能玩：底部按钮、键盘 `3` `2` `1` `F` `空格`，或点击屏幕放烟花

## 手势映射

| 动作 | 效果 |
|---|---|
| 比出 3 / 2 / 1 | 星尘汇聚成对应数字 |
| 握拳（0 根手指） | 凝成一颗心跳的爱心 |
| 张开手掌（4 根手指以上） | 满屏烟花 + 爱心炸裂 |

